# Día 2 - Python aplicado a datos (4,5 horas)
##   Objetivo: comprender cuándo utilizar Python puro, NumPy o pandas

- 45 min: funciones, iteradores, map, zip y comprensiones.
- 90 min: NumPy, arrays, índices, operaciones y agregaciones.
- 90 min: pandas, DataFrames, columnas, filtros y groupby.
- 45 min: mini proyecto de análisis de ventas.

Hoy vamos a trabajar con Python, NumPy y pandas, partiendo de lo que ya sabes de listas, diccionarios, funciones, comprensiones y `reduce`, sin repasar fundamentos básicos de Python directamente: nos centraremos en las diferencias que importan al trabajar con datos, y entre medias se refuerzan conceptos básicos relacionados.

## Objetivos del día

1\. Python aplicado a datos (45 min)

Funciones, `map`, `zip`, comprensiones y buenas prácticas.



2\. NumPy (90 min)

Arrays, dimensiones, índices, operaciones y agregaciones.



3\. pandas (90 min)

DataFrames, selección, filtros, columnas y agrupaciones.



4\. Mini proyecto (45 min)

Analizar ventas de principio a fin.
