## 2.6. Ejercicios prácticos de NumPy

Ejercicio 1 --> Crear arrays

Crea un array NumPy con los números `5, 10, 15, 20, 25`. Imprime su tipo, su `shape` y su número de dimensiones.

Ejercicio 2 --> Operaciones vectorizadas

Con `precios = np.array([20, 15, 12, 10])`, calcula un array con el IVA del 21 % incluido. No uses bucles ni comprensiones.

Ejercicio 3 --> Filtrado

Dado `valores = np.array([12, 55, 31, 80, 42, 9])`, selecciona solo los valores superiores o iguales a 40.

Ejercicio 4 --> Matrices y ejes

Crea esta matriz y calcula la suma de cada columna y de cada fila:

```python
datos = np.array([    [2, 4, 6],    [1, 3, 5]])
```

Ejercicio 5 --> Mini análisis de ventas

```python
precios = np.array([20, 15, 12, 10])

unidades = np.array([3, 7, 2, 4])
```

Calcula los importes por producto, la facturación total, la media de los importes y el importe más alto.
